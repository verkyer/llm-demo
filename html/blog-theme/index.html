构建轻量级现代化设计系统：从零到一的思考

林微远
发布于 2026-05-18 • 1.5k 阅读

在当前的数字产品研发环境中，“设计系统 (Design System)” 已经成为团队提效与保障视觉品质的核心工具。然而，许多团队在创建设计系统之初就陷入了一个误区：过度设计与冗余资产。

他们花费数月时间设计了数百个高复杂度的变体和巨大的圆角卡片，最终由于使用成本高昂而遭到抛弃。在本文中，我们倡导一种克制的、摒弃繁琐组件及多余边角的设计方向，让页面回归内容的朴素与澄澈。

一、为什么摒弃大圆角与超大字号

在极简主义（Minimalism）中，多余的修饰是需要首先被解构和审视的。过大的圆角和极大的字号容易让屏幕的信息负载能力大幅下降，且产生一种过度张扬、不够沉静的视觉喧闹感。

精致的系统应当通过微妙的变化去传递优雅：

  • 中立微圆角： 使用 4px（即本系统的 custom-rounded），让边际干脆利落地呈现。
  • 阶梯型字号： 页面主要标题不应超过 24px，正文则在 14px 左右，以获取高密度、不突兀的视界效果。
  • 阴影替代： 利用 1px 的微妙浅色边界（Border）替代深沉飘渺的物理阴影，将页面重新拉回到平面二维几何层级中。

二、基础变量与 CSS 布局架构

通过声明原生 CSS 变量，可以实现更轻量的深色模式变色。所有的系统层声明，均以简单的黑、白、灰色调进行过渡，在亮色和暗色之间达成无感且低能耗的自然更替。

tokens.css 
:root {
  --bg-primary: #fcfbf9;     /* 极致暖灰 */
  --text-primary: #1e293b;   /* 幽深蓝黑 */
  --border-subtle: #e2e8f0;  /* 骨质白灰 */
  --radius-minimal: 4px;     /* 直线中性的4px弧度 */
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #0f1115;
    --text-primary: #cbd5e1;
    --border-subtle: #1e293b;
  }
}

三、自适应 DOM 位置监听的实现

为了让右侧的文章大纲完美响应页面的滚动行为，我们引入了高效且无抖动的 IntersectionObserver 观察器。

observer.js 
const observerOptions = {
  root: null,
  rootMargin: '-80px 0px -75% 0px',
  threshold: 0
};

const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      activateSidebarAnchor(entry.target.id);
    }
  });
}, observerOptions);

四、结语与思索

优秀的网页，不应该将大量高对比度、大体量的资产压制在用户眼中。把视线还给文本，通过紧密和微小却秩序井然的层级关系，在低功耗与高纯度的页面表现之间重寻内啡肽。
